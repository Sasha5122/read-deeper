# Read Deeper

Deep reading with AI in the margin: select a passage → "Ask" → a highlight + private chat thread anchored to that exact passage, in the right margin. One highlight = one thread; threads are isolated and persistent. Full spec lives in the conversation history / README.

## Stack & layout
- Next.js 16 App Router + TypeScript strict + Tailwind v4; Supabase (Postgres/Auth/Storage, RLS on every table); Anthropic API streaming; Stripe subscriptions. Deployable on Vercel or plain VPS.
- `app/` routes + API route handlers; `components/reader/` the reader (hooks: useSelection, useHighlights, useThreads, useMarginLayout); `lib/` domain logic; `supabase/migrations/` schema; `scripts/seed-library.ts`; `tests/` vitest unit tests.
- `prototype/read-deeper.html` — the earlier single-file localStorage prototype, kept for reference only.

## Invariants (do not break)
- The document full text is EXACTLY the concatenation of `document_text.text` in page order; all offsets are global into that string (`lib/extract.ts` → `fullTextOf`).
- Highlights anchor by `{char_start, char_end}` + `{quote, prefix, suffix}` fallback; re-anchoring logic in `lib/anchoring.ts`.
- Thread context = quote + ~600 chars around + own history only — never other threads (`lib/context.ts`).
- Free/Pro gating is server-side only (`lib/usage.ts`, `bump_usage` RPC); never trust the client.
- AI provider: OpenAI (Responses API via `lib/ai.ts`). Model tiers via env: MODEL_DISPATCHER/MODEL_LOOKUP (gpt-5-nano), MODEL_THREAD (gpt-5-mini), MODEL_DOCUMENT (gpt-5), MODEL_EMBEDDING (text-embedding-3-small). GPT-5 models are REASONING models: cheap/fast jobs must pass reasoning effort "minimal" or they burn the output budget thinking; max_output_tokens includes reasoning tokens; time-to-first-token on medium/high effort can be 30-90s.
- Routing: free-text questions go through the dispatcher (`lib/dispatcher.ts` → RoutingTicket: tier + dosed context) executed by `lib/executor.ts`; quick-action buttons use fixed tickets. Calibration is quality-first: when unsure route UP, visible floor = passage tier (mini). Dispatcher failure falls back to passage+600+last2.
- Supabase row types in `lib/types.ts` must stay `type` aliases (not interfaces) or the typed client degrades to `never`.
